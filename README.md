🛍️ Ecommerce Performance Dashboard (Power BI Project)

A fully interactive Power BI dashboard analyzing year-to-date (YTD) sales performance — covering revenue, profit, quantity, categories, regions, and product trends. Designed to help ecommerce businesses monitor KPIs and uncover insights for better decision-making.


📦 Ecommerce Dashboard Overview

This project provides a detailed performance summary for an ecommerce business. The dashboard tracks overall revenue, profit margin, product sales, and customer behavior across regions and categories. The goal is to deliver real-time business insights through dynamic visuals and KPIs.

🎯 Business Objective

To analyze and monitor:

- YTD Sales, Profit, Quantity, and Profit Margin  
- Category-wise sales performance  
- Top and Bottom selling products  
- Sales by region and shipping method  
- Trends in customer segments and product categories  

All built using Power BI for executives and managers to make faster, data-driven decisions.

🧰 Tools & Technologies Used

- **Power BI** – For dashboard development and visual storytelling  
- **DAX** – To calculate dynamic KPIs and performance metrics  
- **Power Query** – For cleaning and shaping data  
- **Excel/CSV** – Assumed source format
